¿Cómo funciona el Método de Romberg?

Combina la Regla del Trapecio con la Extrapolación de Richardson para acelerar la convergencia. Se construye una tabla donde cada columna mejora la precisión de la anterior.

\[ R_{k,j} = R_{k,j-1} + \frac{R_{k,j-1} - R_{k-1,j-1}}{4^{j-1} - 1} \]

Para los ejercicios con datos tabulados (19, 20, 21, 26, 27), se utiliza una interpolación lineal entre los puntos para poder aplicar Romberg.
